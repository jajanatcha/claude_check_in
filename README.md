# เช็คชื่อเข้าเรียน — คลาส Claude AI

![version](https://img.shields.io/badge/version-1.3.0-8fb4f5) **เวอร์ชัน 1.3.0** · อัปเดต 14 พ.ย. 2569 · ดูประวัติการเปลี่ยนแปลงใน [CHANGELOG.md](CHANGELOG.md)

🌐 **เว็บไซต์:** https://jajanatcha.github.io/claude_check_in/

เว็บเช็คชื่อผู้เข้าเรียนที่ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ผู้เรียนกดเช็คชื่อ เซ็นลายเซ็น แล้วระบบจะบันทึกเวลาที่มาถึงลง **Google Sheets** ให้อัตโนมัติ

## ความสามารถ
- กดที่ชื่อเพื่อดูรายละเอียด: ชื่อภาษาอังกฤษ บริษัท ตำแหน่ง อีเมล เบอร์โทร Line ID หมายเหตุ และหัวข้อที่เพิ่มเองได้ (กดเพื่อส่งอีเมลหรือโทรได้)
- ปุ่ม **+ เพิ่มรายชื่อ** และ **แก้ไขข้อมูล** แก้ทุกช่องได้ และเพิ่มหัวข้อรายละเอียดเองได้ เช่น ข้อจำกัดด้านอาหาร
- รายชื่อเรียงตามบริษัท แต่ละบริษัทบอกจำนวนคนที่มาแล้ว
- กดเช็คชื่อ เซ็นลายเซ็นด้วยนิ้วหรือเมาส์ แล้วระบบบันทึกเวลาให้เอง และบอกว่าตรงเวลาหรือสายกี่นาที
- ค้นหาชื่อหรือบริษัท และกรองดูเฉพาะคนที่มาแล้วหรือยังไม่มา
- นำเข้ารายชื่อจากไฟล์ Excel (.xlsx) หรือ CSV รองรับฟอร์มลงทะเบียนที่มีคนที่ 2–5
- บันทึกลง Google Sheets ทุกเครื่องเห็นข้อมูลเดียวกัน โดยเว็บดึงข้อมูลใหม่ประมาณทุก 8 วินาที
- ส่งออกเป็น CSV หรือคัดลอกไปวางใน Google Sheets ได้
- ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูลของตัวเอง ใช้ GitHub Pages กับ Google Sheets ได้ฟรี

## โครงสร้างไฟล์
```
checkin-claude-ai/
├── index.html            # ตัวเว็บ (หน้าตา + การทำงานทั้งหมด)
├── config.js             # ใส่ลิงก์ Google Apps Script ตรงนี้

│   ├── Code.gs           # โค้ดฝั่ง Google Sheets (วางใน Apps Script)
│   └── appsscript.json   # ไฟล์ตั้งค่า Apps Script (ใช้ถ้า deploy ผ่าน clasp)
├── VERSION               # เลขเวอร์ชันปัจจุบัน
├── CHANGELOG.md          # ประวัติการเปลี่ยนแปลง
├── .nojekyll             # ให้ GitHub Pages เสิร์ฟไฟล์ตามเดิม
├── .gitignore
└── README.md
```

## ขั้นที่ 1 — ตั้งค่า Google Sheets (ทำครั้งเดียว)
1. สร้าง Google Sheet ใหม่ 1 ไฟล์ ตั้งชื่ออะไรก็ได้ เช่น "เช็คชื่อ Claude AI"
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมออก แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs) จากนั้นกด 💾 บันทึก
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
5. กด Deploy แล้วอนุญาตสิทธิ์ ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced → Go to … (unsafe) ซึ่งปลอดภัย เพราะเป็นสคริปต์ของคุณเอง
6. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

ชีตจะสร้างแท็บให้อัตโนมัติเมื่อมีการใช้งานครั้งแรก

| แท็บ | เก็บอะไร |
|---|---|
| **Roster** | id, คำนำหน้า, ชื่อ-นามสกุล, ชื่ออังกฤษ, บริษัท, ตำแหน่ง, อีเมล, เบอร์โทร, Line ID, หมายเหตุ, รายละเอียดเพิ่มเติม (บรรทัดละ 1 หัวข้อ รูปแบบ `หัวข้อ: รายละเอียด`) |
| **Checkins** | วันที่, id, คำนำหน้า, ชื่อ, บริษัท, **เวลาเช็คอิน**, มาสาย (นาที), timestamp, ลายเซ็น (ข้อความรูปภาพ) |
| **Config** | ชื่อคลาส, เวลาเริ่มเรียน |

## ขั้นที่ 2 — ใส่ลิงก์ลงในเว็บ
เปิดไฟล์ `config.js` แล้ววางลิงก์จากขั้นที่ 1

```js
window.CHECKIN_API = 'https://script.google.com/macros/s/AKfycb.../exec';
```

> หรือถ้าไม่อยากแก้ไฟล์ ให้เปิดเว็บ ไปที่ **จัดการรายชื่อ → เชื่อมต่อ Google Sheets** แล้ววางลิงก์ วิธีนี้มีผลเฉพาะเครื่องนั้น

## ขั้นที่ 3 — เอาขึ้น GitHub และเปิดเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub เช่น `checkin-claude-ai`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ จะลากวางในหน้าเว็บ GitHub หรือใช้คำสั่งด้านล่างก็ได้
   ```bash
   git init
   git add .
   git commit -m "เว็บเช็คชื่อคลาส Claude AI"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/checkin-claude-ai.git
   git push -u origin main
   ```
3. ไปที่ **Settings → Pages** แล้วเลือก Source = **Deploy from a branch**, Branch = **main** / **(root)** แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์เว็บแบบ `https://<ชื่อผู้ใช้>.github.io/checkin-claude-ai/`

เปิดลิงก์นี้ได้ทั้งบนมือถือ แท็บเล็ต และคอม หรือจะทำ QR Code ติดหน้าห้องให้ผู้เรียนสแกนก็ได้

## ความเป็นส่วนตัว ⚠️
- **`roster.js` มีชื่อ บริษัท อีเมล เบอร์โทร Line ID และข้อมูลจากฟอร์มลงทะเบียนของผู้เข้าเรียน** ถ้าตั้ง repo เป็น Public ทุกคนบนอินเทอร์เน็ตจะเห็นข้อมูลนี้ — **ห้ามอัปโหลด `roster.js` ที่มีข้อมูลจริงขึ้น repo แบบ Public**
  - ทางเลือก A: ตั้ง repo เป็น **Private** (การใช้ GitHub Pages กับ repo Private ต้องใช้แพ็กเกจ GitHub แบบเสียเงิน)
  - ทางเลือก B: เชื่อม Google Sheets แล้วเปิดเว็บ 1 ครั้งเพื่อให้รายชื่อถูกส่งขึ้นชีต จากนั้นแก้ `roster.js` เป็น `window.CHECKIN_ROSTER = [];` แล้วค่อย push ขึ้น Public รายชื่อจะไปเก็บใน Google Sheet แทน
- ลิงก์ Apps Script ใน `config.js` เปิดให้ใครก็ได้ที่มีลิงก์อ่านและเขียนข้อมูลในชีตนี้ได้ ถ้าเว็บเป็น Public ลิงก์นี้ก็จะเป็น Public ด้วย ควรใช้ชีตแยกเฉพาะงานเช็คชื่อ และอย่าเก็บข้อมูลอื่นที่เป็นความลับไว้ในชีตเดียวกัน
- ใครที่เปิดเว็บได้จะกดดูอีเมล เบอร์โทร และ Line ID ของทุกคนได้ รวมถึงแก้ไขข้อมูลได้ ถ้าจะให้ผู้เรียนเปิดเว็บเอง ควรคิดก่อนว่าโอเคหรือไม่ 

## การอัปเดตภายหลัง
- **แก้หน้าเว็บ:** แก้ `index.html` แล้ว commit และ push จากนั้น GitHub Pages จะอัปเดตเองภายใน 1–2 นาที
- **แก้ `Code.gs`:** ไปที่ Apps Script แล้วเลือก **Deploy → Manage deployments → ✏️ Edit → Version: New version** วิธีนี้ลิงก์ `/exec` เดิมจะยังใช้ได้
- **เพิ่มรายชื่อ:** ใช้เมนู **จัดการรายชื่อ** ในเว็บได้เลย (นำเข้าไฟล์ หรือเพิ่มทีละคน) ข้อมูลจะถูกบันทึกลงแท็บ Roster

## การนับเวอร์ชัน
ใช้รูปแบบ `MAJOR.MINOR.PATCH` (Semantic Versioning)
- **PATCH** (1.0.**1**): แก้บั๊ก หรือแก้ข้อความเล็กน้อย
- **MINOR** (1.**1**.0): เพิ่มความสามารถใหม่ที่ใช้กับชีตเดิมได้
- **MAJOR** (**2**.0.0): เปลี่ยนโครงสร้างชีต หรือต้องตั้งค่าใหม่

ทุกครั้งที่ออกเวอร์ชันใหม่ ให้แก้ `VERSION`, `APP_VERSION` และ `CHANGES` ใน `index.html` ให้ตรงกัน (แก้ `VERSION` ใน `apps-script/Code.gs` เฉพาะเมื่อแก้โค้ดฝั่ง Google Sheets) จากนั้นบันทึกสิ่งที่เปลี่ยนใน `CHANGELOG.md` แล้วทำ tag บน GitHub
```bash
git tag v1.3.0
git push origin v1.3.0
```
เลขเวอร์ชันของเว็บแสดงเป็นป้ายบนหัวเว็บและที่ท้ายหน้า กดเพื่อดูประวัติทุกเวอร์ชันได้ (ประวัติในเว็บอยู่ในตัวแปร `CHANGES` ใน `index.html` เพิ่มรายการใหม่ไว้บนสุดทุกครั้งที่ออกเวอร์ชัน) และถ้าเชื่อม Google Sheets แล้ว จะแสดงเวอร์ชันของ Apps Script ต่อท้ายด้วย

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| ขึ้นว่า "เชื่อมต่อ Google Sheets ไม่ได้" | ตรวจว่าลิงก์ลงท้ายด้วย `/exec` และตอน Deploy ตั้ง Who has access = **Anyone** |
| แก้ Code.gs แล้วไม่มีผล | ต้อง Deploy เป็น **New version** ทุกครั้ง |
| เปิด `index.html` จากเครื่องตรงๆ แล้วคัดลอกไม่ได้ | ให้เปิดผ่าน GitHub Pages (https) |
| ลายเซ็นไม่ขึ้นในชีต | ลายเซ็นเก็บเป็นข้อความรูปภาพ (data URL) ดูได้ในเว็บ เมื่อกดที่ชื่อคนที่มาแล้ว |
