    จัดการรายชื่อ

    นำเข้ารายชื่อจากไฟล์

    รองรับ .xlsx .xls .csv — อ่านคอลัมน์ ชื่อ-นามสกุล (รวมคนที่ 2–5 จากฟอร์มลงทะเบียน), คำนำหน้า, Name-Surname, บริษัท/หน่วยงาน, ตำแหน่ง, Email, เบอร์โทร ชื่อซ้ำจะถูกข้ามให้อัตโนมัติ

    เพิ่มทีละคน

    กรอกชื่อ ข้อมูลติดต่อ และหัวข้อรายละเอียดอื่นๆ ที่อยากให้แสดงตอนกดดูชื่อ

    ตั้งค่าคลาส

    เชื่อมต่อ Google Sheets

    วางลิงก์ Web app จาก Google Apps Script (ดูวิธีใน README บน GitHub) เพื่อให้ทุกเครื่องใช้ข้อมูลชุดเดียวกัน — เว้นว่างไว้ถ้าจะใช้เครื่องเดียว

    ส่งออกข้อมูลวันนี้

    ไฟล์ CSV เปิดได้ใน Excel และนำเข้า Google Sheets ได้ทันที หรือกดคัดลอกแล้ววางลงใน Google Sheets
